# Local secret policy

Run `make secrets` to create `.secrets/` with random development passwords and an operator token. The directory is mode 0700 and ignored by Git. The PostgreSQL app and Neo4j secret files themselves are mode 0644 because their official containers read them as unprivileged users from bind mounts; the parent directory blocks other host users from traversing to them. This container-access choice must be rechecked on other hosts. `.env` holds only image references and non-secret settings. Do not put secrets in `VITE_*` variables, frontend bundles, command-line flags, logs, or model prompts. Rotate local secrets by replacing the files and restarting the affected services; an existing PostgreSQL volume additionally requires an explicit password change in SQL. Keep production secrets outside the repository and use mounted secret files.
