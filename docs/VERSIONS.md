PostgreSQL and Neo4j were pulled and their connections verified; backend and web images were built with their pinned parents. The MiniLM revision was read from the Hugging Face model API; Phase 07 bundled its tokenizer metadata and Phase 08 downloaded the pinned weights and verified local 384-dimensional inference. The upstream Qwen revision is `cdbee75f17c01a7cc42f958dc650907174af0554` from the [model API](https://huggingface.co/api/models/Qwen/Qwen3-4B-Instruct-2507).
