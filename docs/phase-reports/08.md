## Decisions and limits

The exact eligible corpus is the reference for both text methods; no ANN or global full-text index is enabled. RRF scores and graph support are ranking signals, not probabilities or fault proof. The small relevance fixture is developer-authored; independent review is pending. No retrieval-quality gain is claimed from implementation or smoke tests. Model weights are obtained once for the pinned revision and are bundled into the backend image; runtime inference is offline. The optional passage reranker remains disabled. Strict source-available replay cannot run on the synthetic fixture without reliable availability timestamps.
