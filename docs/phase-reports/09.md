## Failures repaired and decisions

The first CLI smoke call used a relative artifact root, which the immutable artifact store rejected. The CLI now prefixes relative roots with the current directory while preserving symlink checks. A first integration run caught the baseline-end boundary being treated as an analysis period; the service now returns insufficient evidence there. The full regression initially expected PostgreSQL migration `0004` and failed, leaving a queued test job that caused later test failures. The assertion was updated to `0005`, and the full suite passed. A test that removed an `Incident` node did not invalidate a published snapshot; the adversarial case now removes the `Snapshot` marker that the graph reader actually verifies. The public healthy fixture has a quiet cutoff that returns `no_anomaly_detected`, while its final cutoff can exceed the initial anomaly threshold; this remains a known false-alarm risk rather than a label-based runtime exception.

The `heuristic-v1` score and `tracecause-template-v2` prompt/version hash are stored in provenance. Scores are ordering signals, not probabilities or proof of cause. The result uses `generation_origin=TEMPLATE`, no model digest and no paid key. Strict source-available replay rejects synthetic traces without reliable availability. Human-reviewed semantic entailment and accuracy evaluation remain future work. The CLI is the Phase 09 interface; the HTTP API and product frontend remain later phases. Artifact and graph publication are not an atomic cross-store transaction.
