## Decisions and limitations

PostgreSQL owns status and references; the artifact repository is content-addressed, and future Neo4j projection is a separate publication step. The import transaction atomically marks both job success and episode import. Artifact files and SQL cannot share a transaction, so a DB registration failure may leave an unregistered file for reconciliation. A long import transaction does not heartbeat mid-transaction; the row lock protects it against a second claimant, while the 25 MiB input cap bounds work. `backup-metadata` stores revision and counts only; full data backup/restore remains Phase 18. The Docker image build emitted `InvalidDefaultArgInFrom` warnings for required build arguments even though both images built successfully. No graph snapshot, anomaly signal, investigation, captured telemetry or model result is claimed by this phase.
