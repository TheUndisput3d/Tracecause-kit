## Decisions and limitations

The selected investigation start is operator supplied and must be an observable 10-second boundary; no injector onset is used. Event-time and available-time replay are separate; synthetic fixtures have no availability timestamps, so their verified run used event-time. Service request metrics use SERVER spans only. A matched CLIENT duration is labeled separately in one dependency observation; an unpaired CLIENT lacks a validated callee and yields a quality flag rather than a fabricated edge. Missing parents, async spans, non-overlapping clocks and too-deep ancestry are flagged. Sampling, sparse traffic and missing spans can bias measurements. A signal describes a symptom, not the root cause. The Docker build still emits warnings for required build arguments but succeeds. No graph snapshot, trained model or fault-location accuracy is claimed.
