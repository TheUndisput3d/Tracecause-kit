1. Add typed HTTP views, scoped pagination/errors/authentication and bounded multipart staging.
2. Add API import/investigation queue submissions with workspace/kind idempotency, queue caps and snapshot freezing.
3. Reuse domain ingestion, graph publication and investigation services in a durable worker; heartbeat, retry and cancellation guards protect publication.
4. Implement all specified reads, safe report publication, readiness and owner-mode examples; export OpenAPI/TypeScript.
5. Verify real HTTP import → durable job → READY snapshot → investigation → citation, plus authorization/scope/limit/cancellation adversaries. Keep frozen evaluation artifacts unchanged.

Existing captured grounding findings remain release requirements and will be repaired separately from frozen benchmark measurements.

## Implemented behavior

Complete API inventory in `src/tracecause/api/`: safe config/auth, episode paging/detail/series, graph, evidence, jobs/cancellation, durable imports/investigations, saved results/export and published aggregate reports. Public mode rejects mutations before body consumption. Operator bearer comparison is constant-time. Multipart staging checks streamed request size, declared names/counts/extensions, file sizes and hashes, with private server-generated directories.

`jobs/api_jobs.py` serializes admission and canonical idempotency in PostgreSQL; snapshot identity freezes at submission. `jobs/api_worker.py` runs the existing domain pipeline with heartbeat, bounded retry and cancellation/publication guards. Import stages are hidden from public job reads. Deterministic snapshot IDs allow interrupted retries and immutable READY replay. SQL result publication and job completion share a transaction. API submission and publication audit events link request IDs; worker logs expose safe stage timings. Historical start times remain null; new jobs have persisted first-start and finish timestamps.

Migration 0006 adds the API idempotency index and job timestamps. Multi-source telemetry normalization and authored Markdown ingestion reuse existing domain validation. SQL connections/query locks and graph reads have explicit timeouts. Health checks real storage and a recent active projection; optional local model metadata failure is degraded capability, without generation. OpenAPI, JSON Schemas and generated TypeScript agree. `docs/API_LOCAL.md` documents a working local owner/replay setup and import-to-citation client.

## Security, data and remaining limits

No new external deployment, paid service or GitHub push. Public outputs contain scoped IDs and content hashes, not host source paths or credentials. Single workspace/single operator remains the supported scope. Wire-level multipart cap includes framing. Readiness validates all active SQL states and the latest active graph marker; it is not a full projection audit. No model execution occurs in request handlers. Existing frozen benchmark source/output artifacts remain unchanged.
