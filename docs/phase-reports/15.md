## Limits and release follow-up

No public hosting or GitHub push. Browser boundary simulations are not backend/model evidence. Browser tests run real loopback API/worker with real containerized databases; full release-container/fresh-volume gates remain phase18. Route splitting reduces initial loading, but the build still reports large entry/workbench chunks; measure and optimize in phase17 rather than inventing latency claims. Neo4j Community isolation and deeper recovery are phase16 work.

Phase13's frozen template grounding gaps remain release requirements. Old benchmark/output artifacts are preserved; a separately versioned grounding repair and explicit verification must precede release. A nominal healthy trace can cross the initial anomaly threshold; quiet-cursor UI coverage does not establish healthy specificity. UI comparison is a retrieval-method diagnostic, not a new five-system benchmark. The read-only evaluation contract does not contain all private run metadata and marks that absence.
