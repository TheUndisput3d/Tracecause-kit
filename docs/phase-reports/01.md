# Phase 01 — domain contracts and validated configuration

Date: 2026-10-10. Status: **PASS** for R02. Prerequisite Phase 00 passed in `00.md`, commit `bdb0627`; its database and build checks were rerun.

## Goal and implementation

Define boundary contracts before ingestion, persistence and HTTP routes. `src/tracecause/contracts/models.py` now has strict Pydantic models for source metadata, manifest, normalized span, service identity, aggregate observation, document/chunk/assertion, snapshot, job, import request/report, retrieval request/result, evidence bundle, hypothesis/claim/narrative, investigation result, graph response/path, sanitized evaluation report/manifest and error envelope. Explicit enums separate origin, statuses, generation, retrieval, ranking and temporal modes. Decimal-string nanoseconds avoid JavaScript precision loss. Nullable metrics preserve unknown versus measured zero.

`src/tracecause/config/settings.py` validates the complete `configs/defaults.yaml` tree with bounds and unknown-key rejection, then applies explicit environment overrides. It validates artifact roots, database URI/port, MiniLM dimensions/revision, provider allowlist, generation budgets, local-model opt-in and file-backed secrets. Public read-only/template mode is the default. `src/tracecause/api/main.py` loads this configuration at process import, so invalid settings fail startup. The backend image copies the YAML file.

`src/tracecause/contracts/canonical.py` hashes original bytes separately from sorted canonical semantic records. `interfaces.py` defines typed repository/provider protocols and safe failure categories without runtime test fakes. `scripts/export_contracts.py` exports 24 JSON Schemas and `contracts/openapi.phase01.json`; `apps/web/src/lib/api/generated.ts` is produced by `openapi-typescript`. `scripts/check_frontend_types.py` and `make check` detect generated-file drift. The OpenAPI file has the liveness route plus domain components; full domain routes are Phase 14 work.

Documentation changed in `contracts/README.md`, `docs/CONFIGURATION.md`, `docs/DECISIONS.md`, `docs/adr/0002-local-model-configuration.md`, `docs/VERSIONS.md`, the dependency inventory, the status/build log and `README.md`. `pyproject.toml`/`uv.lock` added the verified `types-PyYAML` stub dependency. The root Makefile now has `make contract` and `make test-contract`.

## Decisions, data boundaries and limitations

ADR 0002 records the conflict between the Phase 01 prompt's dated pricing configuration and the specification's local Ollama/no paid runtime policy. Local model mode requires explicit operator opt-in, a reviewed model tag and digest, an allowlisted endpoint and resource limits. It does not invent a monetary price. These are config rules only; Ollama weights/inference are unverified.

Unknown fields are rejected at public write/model boundaries. Result validation checks evidence scope, cutoff, citation membership and path direction; later Phase 09 adds deeper numeric claim/entailment validation. Evaluator truth has no field in runtime request/result models. An OpenAPI component being present does not mean its HTTP route exists yet. No import, graph build, retrieval, investigation, model call, evaluation, capture or dashboard workflow is claimed.
