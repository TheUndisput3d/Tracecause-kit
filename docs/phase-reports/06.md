## Decisions and limits

PostgreSQL owns the active pointer and is authoritative for CALLS support. Neo4j is a rebuildable projection; failure before PostgreSQL READY leaves the prior active snapshot. Readers pin one ID and validate source spans at the cutoff. A CALLS edge is communication evidence, not causal proof. Available-time replay is deliberately rejected for synthetic OTLP imports without reliable availability timestamps. The optional document/vector indexes are deferred until their adapter exists. Retiring a graph snapshot does not delete episode artifacts; shared artifact reference counts need a separate later policy. Reader leases last 30 seconds and need renewal if future API requests can run longer. The phase's real integration tests use disposable PostgreSQL databases and delete only their own Neo4j snapshot IDs.
