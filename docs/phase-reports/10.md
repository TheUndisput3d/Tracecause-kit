## Decisions, failures and limits

The first three-candidate Qwen draft exceeded the 1,000-token output budget; an initial one-candidate attempt changed typed support and correctly fell back. Model mode now exposes the highest-ranked candidate and explicitly records that limit. The final five outputs passed the structural and source validator. Initial tests expecting the earlier task wording and template's three-candidate fallback were corrected; the full suites then passed. `tracecause-template-v3` invalidates earlier cache identities after direct-service selection for no-anomaly reports.

The accepted model outputs largely copy the grounded template. This proves local schema/capability and validator integration, not independent explanation quality. The deterministic validator checks typed support and rejects common unsupported prose forms; it cannot prove free-text semantic entailment. The host-native Ollama version differs from the pinned optional Compose image, whose volume needs its own explicit model pull. Model weights and local audit outputs are ignored artifacts, not committed.

An attempted pull of the optional pinned Compose image was cancelled after the offline inference gate passed with the already installed host Ollama binary; this phase does not claim that the optional image itself ran. The disposable inference container had Docker networking disabled, and the backend image also loaded both pinned tokenizers/embeddings without networking.
