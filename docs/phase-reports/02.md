# Phase 02 — seeded fixtures and evaluation protocol

Date: 2026-10-10. Status: **PASS** for R03. Prerequisite: Phase 01 passed in `01.md`, commit `e525c37`.

## Goal, implementation and files

Build reproducible synthetic OTLP telemetry and a frozen grouped evaluation protocol while keeping evaluator truth outside runtime inputs. `scripts/fixtures.py` generates parent-linked CLIENT/SERVER spans for topologies A/B/C, status and latency changes, client timeouts, volume changes, healthy runs, independent distractor errors, missing parents, duplicate delivery, skew and out-of-order records. Opaque episode IDs and neutral titles keep injector choices out of public metadata. `scripts/validate_fixtures.py` verifies public files, hashes, IDs, durations, duplicate handling and private split/truth consistency when explicitly invoked. The runtime `src/tracecause/ingestion/source_allowlist.py` accepts only declared regular files in a flat episode directory and rejects sidecars and symlinks.

The 24 group definitions are fixed in the evaluator-side generator before model tuning. Four healthy groups are allocated 2/1/1. Topology C is held out for the test split. The one-episode public smoke fixture is committed under `data/fixtures/smoke/`; full generated public data under `data/generated/` and all private truth under `data/gold/` are Git ignored. The backend image copies no generator, data directory or private truth. `docs/EVALUATION_PROTOCOL.md` freezes questions, judgments, eligibility and metric denominators. `docs/DATA_CARD.md` records intended use and limitations. `data/evaluation/annotation_template.csv` and `annotation_examples.json` are implementation-authored drafts and explicitly require independent human review.

## Decisions, limitations and next phase

The original Phase 01 baseline validator incorrectly required the baseline to end before the episode event interval. Phase 02 smoke generation exposed the inconsistency with the manifest contract; it now requires the baseline to lie inside the event interval. The simulator's data is structurally controlled, not a real capture. Timeout and volume cases are provisionally marked unidentifiable; they require human annotation before scored evaluation. The draft examples are not accepted gold. No captured data, model result or production validity is claimed. No Phase 02 gate remains blocked; human review belongs to later scored evaluation.
