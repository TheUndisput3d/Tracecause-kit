# Prioritized future work

1. **Independent evaluation:** review source-linked labels/claims with independent
   annotators, predeclare a new split and expand identifiable captured cases before
   tuning anything. Keep the current frozen outputs as historical evidence.
2. **Grounding quality:** measure whether template v8 and compiled evidence plans improve semantic support on
   new reviewed data; include question intent, abstention, baseline distributions
   and path statements. Current regression checks are not that experiment.
3. **Operational measurements:** capture trustworthy arrival/drop counters, test on
   the actual small deployment target and measure failure/load distributions beyond
   the current controlled runs. Measure the compiled-plan local generation path across hardware without relaxing
   provenance, admission fences or deadlines.
4. **Usability:** test with real operators, improve large frontend chunks and
   accessible explanation of truncation; preserve source inspection on small screens.
5. **Data/model breadth:** extend the three captured application topologies beyond
   two incidents each, include larger historical archives and independently
   reviewed operational documents, and assess calibration and distribution shift.
   The existing change-ordering experiment uses known controlled scenarios;
   new applications are needed to measure generalization. Optional ANN, reranking, GPU and Astronomy
   Shop are experiments, not existing project capabilities.
6. **Public operations, only after approval:** select a host/domain, configure
   publicly trusted TLS and firewall policy, perform external exposure/security
   checks, and review redistribution licenses/data before any publication.

Automatic remediation and unsupported causal claims are outside this version's
scope. Future work must be measured and versioned, not folded into old benchmarks.
