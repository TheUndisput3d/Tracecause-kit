# Sanitized measured evaluation exports

These are byte-for-byte copies of the two schema-validated aggregate exports from phase13. They contain actual frozen synthetic120-episode and captured24-episode results, including negative findings and undefined denominators. They are not regenerated during CI, not accuracy results for later runtime repairs, and contain no raw traces, private labels or episode-level judgments.

They are included so a fresh local installation can seed the dashboard's measured evaluation view without depending on ignored developer reports. Source context: `docs/EVALUATION_RESULTS.md` and `docs/phase-reports/13.md`. Reports are created by this project, licensed Apache-2.0. No independent human review or production validation is claimed.
